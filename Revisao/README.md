# Revisão de Programação para Web

Esta pasta reúne exercícios e projetos desenvolvidos durante a revisão dos conteúdos estudados anteriormente na disciplina de Programação para Web.

O objetivo é reforçar os conceitos de programação e desenvolvimento backend, com foco na construção de APIs REST utilizando Node.js e Express, integração com banco de dados e aplicação dos conhecimentos na prática.

## Conteúdos revisados

- [ ] TypeScript
- [ ] APIs REST e métodos HTTP
- [ ] Express.js
- [ ] Programação assíncrona (`async/await`)
- [ ] Integração com banco de dados
- [ ] Operações CRUD

Os conteúdos serão adicionados gradualmente, conforme o avanço dos estudos e a realização dos exercícios práticos.
